# E-Commerce Sales Performance Analysis

## Project Type
Portfolio Data Analyst Project

## Business Problem
Evaluate e-commerce sales performance across time, region, category, product, and sales channel to identify revenue and profitability patterns.

## Analytical Workflow
1. **Data Preparation** — reviewed source-style transaction data for duplicates, missing categorical values, and consistency issues.
2. **Data Cleaning** — created a cleaned analytical dataset and validated calculated fields.
3. **SQL Analysis** — calculated KPIs and analyzed monthly, regional, category, product, and channel performance.
4. **Python Analysis** — used Pandas/NumPy for cleaning, KPI calculations, and grouped exploratory analysis.
5. **Power BI** — designed a decision-focused dashboard with KPI cards, trends, rankings, and slicers.
6. **Business Interpretation** — translated analytical results into findings and practical recommendations.

## Key KPIs
| KPI | Result |
|---|---:|
| Revenue | ₹12,583,439 |
| Profit | ₹3,789,315 |
| Profit Margin | 30.1% |
| Orders | 1,200 |
| Units Sold | 5,364 |
| Average Order Value | ₹10,486 |

## Key Findings
- West generated the highest revenue among regions.
- Electronics was the highest-revenue category.
- Storage Set was the top product by revenue.
- Website was the highest-revenue sales channel.
